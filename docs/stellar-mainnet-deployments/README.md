# Historical Mainnet preparation evidence

The preflight and prepared deployment JSON files here describe the earlier
signed-score candidate. That candidate was never deployed to Mainnet and was
superseded by independent Pulse verification before signing. These files are
historical evidence, not a current deployment plan, quote or authorization.

Use `../stellar-verified-deployments/` for the independently verified Testnet
candidate and `../stellar-independent-verification-review.md` for current
implementation, validation and remaining Mainnet approval gates.

The before/association audit files preserve historical database and wallet
association evidence. They contain public metadata and fingerprints, not keys.
